# 消费者购物车记忆优化（2026-11-27）

取消 U09 收藏夹，保留原有按账户保存购物车及匿名本地暂存。复用原接口与迁移039，无新增数据库迁移。

本轮：账户登录状态加载及退出触发购物车刷新；窗口重新聚焦时重新读取；完整购物车认证异常不降级为访客；新前端保存时提交预期账户ID，后端拒绝陈旧账户的写入（旧客户端兼容）。

待验收：实际退出与登录、同一账户跨设备恢复、切换账户隔离、访客合并及网络响应丢失后的幂等重试、商品下架后移除、价格库存更新。访客合并幂等机制尚未改造。未执行生产部署或正式数据库操作。


## 二期：访客合并幂等（195）
账户购物车服务端在同一事务中锁定购物车、登记全局唯一合并 ID、合并访客数量与保存记录。重试已提交的同一批次返回当前购物车，不重新增加商品；更改批次内容、跨账户重用编号拒绝。浏览器保留待确认批次，确认后才删除访客记录；登录角标、购物袋和完整购物车共用合并方法。现代安全来源使用 Web Locks 跨标签协调，旧浏览器及非安全来源只保证同标签序列化；极端跨标签冲突保留原记录并提示。待确认批次要求原账户重试，不向新账户合并。新增迁移195；不改正式数据库、不部署。待隔离库验证及双设备浏览器实测。
- 合并超限或商品不可售的明确事务回滚响应会释放待确认批次（保留本地商品）；网络超时或其他不确定响应仍保留原批次，禁止误清除。若需要编辑无法合并的访客商品，可退出后编辑访客购物车再登录。
