# K14 简化经销商权益
不做员工、等级、积分。业绩使用订单创建时有效的企业关联，签收时间（Europe/Berlin）归月，排除未签收/取消、未完成报价，扣减已实际接收的退货价值；EUR/CNY 分开。仅 EUR 产生返利，按单个企业、政策有效期、明确百分比，政策创建默认停用；启用时不允许重叠日期。每个订单最多一笔待审/已批准返利；生成和审批时核对订单金额及未完成退货。样车/展会/营销补贴手工登记待审。审批记不可变权益流水，冲销追加反向流水。后续退货导致原基数变化时提示复核，需冲销后重算。当前不把权益流水当作银行流水，不支持实际抵扣采购款：须下一阶段联动应收余额、银行收款、退货退款、发票、抵扣冲正与会计凭证后上线。无默认返利率，无自动产生返利，无真实资金操作。迁移193、CI、隔离库及真实页面验收待执行。

## 抵扣二期（194）
Admin 按单笔已审核权益向批准后新建的同企业 EUR 已开票订单登记非现金抵扣；只允许无有效退货的订单。严格限制权益余额和发票应收余额，不写银行收款，不改变发票原始金额。抵扣及冲销不可变；应收、银行收款上限同步减去生效抵扣。实际退货收货时自动冲销该订单全部权益抵扣，恢复权益余额，原返利订单基数变化冻结新抵扣，已用原返利需先撤回再冲销。会计凭证由管理员在登记前核对，暂不自动生成会计/税务凭证。待隔离数据库验收，未部署。
