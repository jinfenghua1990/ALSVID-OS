# K13 企业员工权限一期
六个业务角色：企业管理员、采购、财务、店长、店员、售后。按当前企业关联分配，已有活跃关联迁移为 legacy，新关联无授权时为 pending。平台 Admin 可分配所有新角色；企业管理员仅能调整本企业已关联非管理员、非 legacy 员工，不得自我提权或跨企业调整。权限变化撤销目标账号现有会话。受管账号禁止访问旧门户业务 API，后端统一检查明确路由，前端按角色显示工作区。采购可查看订单财务字段（现有订单接口不可细分字段），财务仅查询订单，员工订单仍按账号隔离；门店角色当前覆盖本企业所有授权网点，未细分单门店。新账号由 ALSVID Admin 创建审核并关联；未开放企业自主开户/邀请、共享订单、门店级 RBAC。已开始的请求不保证被撤销立即中止。迁移 192 与隔离库/实际登录验收待执行。
