# 官网模块化装修建设框架

状态：目标架构与开发契约，不代表全部已实现。以根目录 AGENTS.md 和 storefront-builder-checklist.md 为接管依据；修改架构需记录原因及兼容方案。

## 1. 优先范围与菜单
官网优先，Admin 只优先建设支撑官网的能力。复用商城运营、商品管理及现有店铺装修工作区，不额外创建孤立系统。

| 功能 | 子功能 |
|---|---|
| 商品管理 | 整车/配件关联、商品上架、SKU、价格、活动价、SEO、素材 |
| 网站装修 | 页面管理、页面模板、商品模板、可视化编辑器 |
| 全局装修 | Header、公告栏、主导航、Footer、设计令牌 |
| 模块库 | 内容模块、数据绑定模块、共享模块、受保护业务模块 |
| 模板库 | 保存、套用、默认模板、商品覆盖、版本及引用关系 |
| 发布管理 | 草稿、Draft Mode、独立发布、历史、对比、撤回、回滚、缓存 |
| 官网交易运营 | 账户、购物车、结账、订单、支付、配送、VAT、售后、经销商 |

生产、财务、复杂库存、供应商深度管理暂缓，不移除已存在的业务能力。

## 2. 页面覆盖矩阵

| 页面 | 模板 | 固定能力 | 可装修内容 |
|---|---|---|---|
| 首页 | 首页 | 全局导航/页脚 | KV、产品卡、卖点、品牌、营销 |
| 整车/配件分类 | 集合 | 真实商品、筛选、排序、链接 | 分类导航、横幅、卡片 |
| 商品详情 | 商品模板 | 主图、SKU、价格、购买、参数、评价等八区 | 图文、视频、FAQ、卖点、营销 |
| 品牌/技术 | 内容页 | 全局框架、SEO | 图文、视频、技术 |
| 活动/专题 | 内容页 | 真实商品/活动关联 | 轮播、CTA、商品集合 |
| 新闻/公告 | 列表/文章 | 真实文章与日期 | 列表、图片、正文 |
| 客户服务 | 服务页 | 联系、订单查询、工单、说明书 | FAQ、引导、说明 |
| 经销商 | B2B 服务页 | 申请、登录、权限、经销商查询 | 合作说明、CTA |
| 法律政策 | 政策页 | 正式政策、有效版本 | 文本、目录 |
| 购物车/结账/账户 | 受保护业务模板 | 业务校验、鉴权、真实交易 | 限定视觉配置 |

现有 CMS 类型有限，首页仍有独立引擎。上表为目标分类，不强制一次增加所有数据库枚举。迁移必须保留原有 URL、SEO、历史和正式内容。

## 3. 数据与引用关系

页面 = 全局布局 + 页面模板 + 模块引用 + 业务数据。
整车主档 -> 商品关联 -> 当前商品上下文 -> 参数模块 -> 官网。
共享模块 -> 模板/页面引用 -> 发布版本解析 -> 所有关联页面。

| 数据 | 唯一维护源 | 引用规则 |
|---|---|---|
| 整车工程参数 | products.specs + fields | 当前 productId + field code |
| SKU/版本/颜色/法规 | 现有产品及 SKU 主数据 | 关联商品，不手写替代 |
| 价格/活动/库存 | 现有销售与库存接口 | 购买模块读取真实数据 |
| 标题/SEO/营销文案 | 商城上架及发布数据 | 商品发布版本与语言 |
| 主图/详情素材 | 素材库及商品资产关联 | assetId、顺序、用途 |
| 页面结构/样式 | CMS 与模板配置 | 读取已发布配置 |
| 公告/导航/页脚 | 全局共享模块 | 读取已生效版本 |
| 评价、适配配件 | 评价及适配关系业务 API | 动态读取 |

参数模块：仅配置字段 code、分组、排序、样式、显示范围、语言标签，不录入参数值。只公开启用、商城可见、适用车型、产品级字段；拒绝内部键和敏感内容。缺失值隐藏或明确提示；真实 0 和 false 不丢弃。按语言格式化数值、单位、枚举及文本，避免重复单位和未翻译值。当前主档绑定仍可选，旧商品规格兼容路径仍存在；下一轮要核对迁移和默认切换，不可直接批量公开字段。

同一业务值修改后，所有引用读取同一已生效数据；如果业务主档有审批流程，以通过审批的数据为准。装修草稿独立于业务数据。

## 4. 模块登记与编辑器

| 类别 | 标准模块 |
|---|---|
| 内容 | KV/Banner、单图、轮播、图文、文字、视频、卖点、FAQ、CTA、文章、分隔线、留白 |
| 数据绑定 | 商品卡/集合、参数、商品比较、评价、适配配件、说明书 |
| 共享 | Header、公告、导航、Footer、营销条、服务/政策提示 |
| 受保护业务 | 商品购买区、SKU/价格/库存、购物车、结账、账户、订单、售后、经销商权限 |

每个模块登记稳定 key、schemaVersion、类型、允许页面/区域、属性与绑定 schema、默认值、中文名、渲染器、响应式规则、可见性、素材依赖、编辑权限。新增模块同时检查 API 校验、Admin 属性/预览、Next.js 渲染和测试。未知类型不能静默当成功发布。

编辑器三栏：左侧页面树/模块库/排序及共享状态，中间真实预览，右侧属性/样式/数据绑定。顶部页面、语言、PC/平板/手机、草稿、预览、发布及历史。复用现有 CmsPageManager、ShopDesignWorkspace、ProductDesignPanels。固定购买功能不可被普通拖拽删除。商品详情保留原八区：①主图与购买（技术参数固定区域）②营销③④预留⑤按商品图文⑥评价⑦退换货⑧其他。允许在适用区域扩充内容，不改变核心业务约束。

## 5. 通用共享模块与模板（目标契约，未实现）

先核对已有表及发布 API 后再决定实际表名，不创建重复数据库。
- ModuleDefinition：moduleKey/schemaVersion/属性校验/渲染器/区域限制。
- SharedModule：稳定 moduleId、语言内容、draft revision、publishedVersion、状态。
- Template：templateId、pageType、语言组、区域规则、模块引用、草稿及版本。
- Page：pageId、path、locale、templateId、页面独立内容、发布版本。
- ModuleRef：moduleId + mode（follow / pinned / independent）；follow 默认跟随共享模块已发布版本，pinned 固定版本，independent 为显式独立副本。
- 商品上下文：复用既有 productId 和 SKU；商品特有内容与共享模板分开，禁止通过整个模板复制断开共享关系。
- 维护模块→模板→页面→商品的依赖图；显示引用数、影响范围，禁止循环引用，有引用的模块不可直接删除。
- 统一设计令牌：字体、颜色、按钮、间距、断点、圆角；只允许受控局部覆盖。

## 6. 发布与版本契约

草稿编辑 -> 校验 -> 持久化版本快照及引用版本 -> 更新生效指针 -> 刷新影响范围缓存 -> 前台验收。
快照写入失败必须阻止发布。发布后的缓存失败需明确显示“已发布、缓存刷新待重试”，不能假报前台已更新。撤回/回滚必须刷新。历史页面预览应固定当时的视觉模块版本，同时明确业务实时数据不等于历史快照；旧快照不可改写。Draft Mode 必须鉴权、不缓存、不被搜索引擎收录。共用发布契约而非强迫不同业务数据使用同一张表。
