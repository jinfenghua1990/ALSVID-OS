## 3. 各模块边界与装修权限

| 模块 | 数据来源 | 功能和装修边界 |
| --- | --- | --- |
| P00 | 当前商品名称、全站共用菜单/购物车/账户功能 | 单行吸顶导航；概览到 P02、参数到 P05、下载到 P07、配置车型到 P01；滚动对应栏目高亮。隐藏选配时进入同一商品 URL 的 configure=1 配置模式。 |
| P01-01 | 商品、SKU、价格、颜色、配件 | 车型选配、购买与购物车；复用现有交易逻辑。 |
| P01-02 | 整车主档参数字典 | 固定四项展示槽位，默认重量、续航、车架材质、折叠尺寸；可替换字段、展示开关；主档数据只读，不造假值。原配置 modules.performance 保留。 |
| P02 | 车型独立装修与商品资料 | 全幅主视觉、图片/视频、营销文案；兼容旧公共营销回退。 |
| P04 | 车型及语言独立装修 | 全幅沉浸式图文容器，先全车后细节；透明素材、文字叠加、滚动动画。 |
| P05 | 整车主档公开参数 | 自动分类（车架、电气、骑行、机械、其他）；装修控制分组与样式，不重复录入技术参数。 |
| P06 | 当前车型公开包装字段 | 实物图、名称、数量按已有资料展示；缺数据不造示例。 |
| P07 | 已公开发布且关联当前车型的文件 | 产品说明书、安装指南等，当前实现为 PDF；不得暴露内部文件。 |
| P08 | 当前车型独立 FAQ | 独立展示和管理，不强制车型间共用同一内容。 |
| P09 | 当前车型质保及售后资料 | 可引用共用规则库，但须匹配车型；不强制所有车型内容一致。 |
| P10 | 当前车型、销售地区配送资料 | 可引用共用规则库，但须匹配车型和地区。 |

P01 两个子模块共用背景、独立展示开关。P06—P10 独立组件、独立控制展示，不合并为服务与支持。共用的是组件与规则机制，不是强制共用车型内容。

## 4. P04 沉浸式图文装修

设计目标：全幅连续展示，不使用固定左右分屏、独立白底卡片或边框。默认透明商品素材、继承背景、文字叠加并随滚动渐入；也可使用全幅场景图或视频。子模块之间自然过渡，支持 PC 和移动端位置、比例分别设置。

| 设置类别 | 选项 |
| --- | --- |
| 素材 | 透明商品图、全屏图、视频 |
| 背景 | 继承、纯色、渐变、背景图 |
| 文字 | 标题、副标题、介绍、字号、颜色 |
| 位置 | 图片与文字位置、显示比例 |
| 动画 | 渐入、放大、缩小、平移、局部聚焦、滚动固定 |
| 滚动 | 触发位置、滚动联动、速度、停留距离 |

按车型、语言保存到商品草稿和发布记录；支持新增、复制、删除、隐藏、拖拽排序。设计上不预先固定产品细节数量；当前代码上限为 200 段。P04-01 等为展示顺序标记，不应以序号替代子模块持久化身份。

## 6. 后台统一装修编辑器（2026-11-25 定稿）

### 6.1 一级装修管理页面

- 首页、商品详情页及其他页面使用同一套管理交互，目录按已确定的页面模块及稳定 ID 生成，不另行设计模块编号。
- 左侧为模块目录；右侧为完整页面预览。点击模块，预览定位并高亮相应区域，同时展示该模块的发布状态、草稿和历史版本入口。
- 一级页面只管理、选择、查看及预览，不内嵌装修编辑表单，不因编辑而丢失当前操作状态。
- 首页四区为 G01 公告栏、G02 导航栏、G03 页面主体、G04 页脚；商品详情页按第 2 节执行，公共区域不重复维护。

### 6.2 二级统一装修编辑器

- 所有模块的编辑工作均进入独立二级工作页面（后台独立 TAB），不使用编辑弹窗，不替换一级管理工作区；关闭或返回后保留原页面选中模块、车型、语言和预览状态。
- 全系统只建设一套装修编辑器框架；共用工具栏、素材库、预览、草稿保存、发布及历史版本机制，不为每个模块重复开发编辑器。
- 通过模块稳定 ID 加载对应的组件、可编辑配置项及可选展示风格；模块风格和字段允许不同，但编辑器外壳与通用操作一致。新增模块仅扩展其组件、配置定义和渲染规则。
- 编辑上下文根据页面、模块、车型（适用时）、语言及设备区分；全站公共模块使用共享配置，商品专属模块使用对应车型的配置。产品主档取数和交易数据保持既有业务边界，不在装修器内重复录入。
- 编辑完成先保存草稿，确认预览效果后再发布；保留历史版本及恢复能力。PC 与移动端按同一套框架预览。

### 7.2 L02 快速购买组件

四款车型共用一个组件，分别读取各自数据。展示商品透明底图、名称、核心卖点、四项核心参数、颜色选配、实时售价与库存状态、了解详情、加入购物车。选择颜色绑定真实 SKU，并联动对应图片、价格和库存；不允许购买不可售 SKU，购物车服务端校验价格及库存。PC 端两列并排，移动端单列、尽量一屏一款，不强制固定高度导致截断；同一组件响应式适配，不另建两套组件。具体参数和颜色从产品主档取数，不使用示例值冒充真实数据。

### 7.3 全站营销联动

- 黑五等促销由商城运营统一维护营销活动，关联参与的商品或 SKU、市场、有效时间及活动价格；装修器不重复填写销售价格，只控制营销信息的展示样式、位置和可选倒计时等视觉配置。
- 活动生效期间，商品列表快速购买组件及详情页自动读取有效的活动标签、价格、适用的参考价、优惠信息与活动时间。显示划线价或折扣声明前须校验目标市场价格标示规则。没有有效活动则隐藏促销元素，结束后按价格服务重新计算当前应付价，不硬编码恢复某个历史价格。
- G01、首页、商品列表、商品详情及购物车共用营销数据，按活动配置及各自展示权限联动；实际成交价始终由服务端价格/营销规则校验，不能仅修改前端显示。多活动冲突、叠加、市场合规及结算细节实施时核实。
- 新统一装修器沿用第 6 节的模块编辑、版本及强制发布前预览规则；活动价格变动不要求重新装修商品页面。
