# 官网销售订单分批发运
- 188 迁移新增包裹、包裹明细与包裹签收；历史单运单及签收兼容，不迁移历史包裹。
- 每次发运登记一个包裹：车体（不含电池）、电池或配件，同类可包含多个订单商品行，数量可拆分。同一订单每个运单只登记一次。车体与电池分别累计，防止超发。
- 电池运输须人工核实承运商合规要求，不代表系统自动完成危险品审核。订单全额收款后才能发运；部分发运期间不能直接取消或更正收款，需先人工处理异常。
- 整车仍是库存单位：每一订单行所有必需组件发完才一次性扣减整行库存及消耗预占；此前库存仍预占，不单独扣车体或电池。不是零配件库存联动或 VIN/SN 管理。
- 会员/访客逐包裹签收，全部发完且签收后转为 delivered。老整单发运/签收表保留最终状态锚点。
- 未修改已有生产交付、B2B 发运流程。新发运 API 需要 parcelId、component、items；旧单运单仅用于历史读取/签收。
- 待隔离数据库完成迁移和完整发运、签收、回归验收。
